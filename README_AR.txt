فحص وإصلاح مشكلة تصنيف الإعلان الجغرافي - النسخة الثانية

الرسالة «التصحيح مُثبت مسبقاً» في ملف التحديث القديم لا تعني أنه لم يجد المشروع، بل أنه وجد مشروع D:\LMI_PROJECT وتعرّف على شيفرات الإصلاح نفسها؛ لذلك لم ينسخها مجدداً.

المشكلة في الأداة القديمة أنها لا تفحص استدلال النظام فعلياً إذا كان التحديث مثبتاً بالفعل. هذه النسخة تقوم بذلك.

طريقة الاستخدام:
1. فك ملف ZIP في مجلد منفصل (لا تفك ملف zip فوق مشروعك).
2. افتح check_and_repair.bat بالنقر المزدوج.
3. سيستخدم المسار D:\LMI_PROJECT ويطبع مكان المجلد الذي يفحصه.
4. إذا احتاجت الملفات إلى تعديل فسيُنشئ نسخة احتياطية داخل backups ثم يعالجها.
5. حتى لو قال «مثبت مسبقاً»، سيختبر 5 أمثلة جغرافية وفحص التكامل مع المحرك، ويحاول تجربة النموذج الحقيقي.
6. افتح تقرير التشخيص D:\LMI_PROJECT\reports\GEO_FIX_VERIFICATION.txt.
7. أغلق Streamlit القديم بالكامل (Ctrl+C)، ثم شغّله من CMD:
   cd /d D:\LMI_PROJECT
   python -m streamlit run app_dl/main.py

ملاحظات:
- لا يغير أوزان النموذج ولا بيانات التدريب.
- لا يدعي إجراء اختبار كامل لواجهة المتصفح.
- إذا كان النموذج المحلي غير موجود أو إحدى مكتباته ناقصة، يذكر أن اختبار النموذج غير متاح؛ ولا يدعي نجاح هذا الاختبار.
- عند استخدام بيئة .venv في المشروع، يحاول ملف BAT تلقائياً استخدام Python الموجود داخلها.
